# Agent Reach：30 秒操作指南

1. 登录 CRM，打开 **CRM → 内容管理 → Agent Reach**。
2. 查内容：填写关键词，点击一次 **运行搜索**。
3. 看热点：在趋势区域点击一次 **采集趋势**，查看微博、知乎结果。
4. 在 **最近运行状态 / 最近结果** 查看记录；**更新显示**只更新记录展示。

运行中请等待，不要重复提交。出现失败提示请联系管理员。

**深度内容：暂未开放。**

没有菜单或无权访问？请联系管理员申请 Agent Reach 权限。

## 持续关注关键词

点击“新增关键词” → 填写关键词 → 勾选“启用关键词” → 按需要开启自动执行 → 选择频率与墨尔本执行时间 → 保存。

只想手动运行？保持关键词启用，关闭自动执行，然后点击该行“立即运行”。暂停会同时停止手动和自动执行。

趋势需要另外保存自己的自动采集计划。使用“最近任务”查看手动/自动状态和新增结果数；“更新计划显示”不会触发采集。

## 快速查看搜索结果

在已加载结果中选择“综合排序”“最新发布”“点赞最多”或“爆款潜力”，再按发布日期或关键词筛选。这些操作不会重新搜索。当前范围最多 100 条最近采集结果，不是全部历史；“未知”表示尚无可靠数据，爆款潜力仅供参考。

搜索内容范围默认最近30天，可选7天、3个月、6个月、1年或全部，和排序、关键词组合使用；仅筛选已加载结果。关键词编辑可保存自己的默认内容范围。

趋势优先展示“小红书”：使用已保存、匹配启用关键词的内容，不是官方热榜；切换时间或排序不产生采集。微博、知乎仍通过“采集趋势”获取。

页面时间统一为墨尔本当地时间，自动处理夏令时；未知时间不补造。
