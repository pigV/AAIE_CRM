# Agent Reach 中文使用手册

## 进入工作台

登录 CRM，选择 **CRM → 内容管理 → Agent Reach**，进入 **Agent Reach 工作台**。页面地址为 `/agent-reach`。

首批仅管理员可以使用。之后明确获得 Agent Reach 权限的员工也可使用本工作台；拥有其他内容管理权限不代表拥有本模块权限。没有入口或提示无权访问时，请联系管理员。

## 搜索

1. 在“搜索”区域填写“关键词”。
2. 点击一次“运行搜索”。运行期间按钮不可重复点击。
3. 查看“最近运行状态”和“最近结果”。如需查看后续状态，点击“更新显示”；该按钮只读取已保存记录，不会重新运行搜索。

结果展示标题、来源和时间。“暂无结果”表示当前没有可展示的已保存结果，不代表系统故障。

## 趋势

1. 在“趋势”区域确认采集平台为微博、知乎。
2. 点击一次“采集趋势”，等待运行完成。
3. 查看最近运行状态、最近更新时间及最近结果；必要时使用“更新显示”。

## 异常处理

出现“搜索运行失败”“趋势运行失败”或记录暂时不可用时，请联系管理员，并说明操作时间和所用关键词。不要反复点击或刷新后再次提交来尝试补成功。

页面不会自动重新运行搜索或趋势采集。刷新页面只读取已保存记录。

## 深度内容

深度内容显示“暂未开放”，当前不能操作。无需为此进行登录恢复或其他设置。

## 关键词管理与自动执行

“关键词管理”保存需要持续关注的关键词。点击“新增关键词”，填写内容，然后分别设置：

- **启用关键词**：允许运行。暂停后，手动运行和自动执行都会停止；历史结果仍然保留。
- **启用自动执行**：按计划运行。关闭自动执行但保留关键词启用时，仍可点击该行的“立即运行”。

可选择每天、工作日、每周指定一天、每隔若干天或自定义星期，并填写执行时间。所有计划、上次执行和下次执行均使用**墨尔本时间**，不受电脑所在时区影响。“每隔若干天”需要填写起始日期。

每行可编辑、暂停或启用、立即运行、删除。删除前需要确认，删除仅移除后续计划，不删除已采集的历史结果。运行中的关键词暂时不能再次运行、编辑或删除。

“更新计划显示”仅重新读取计划与任务状态，不会触发采集。操作失败或结果不明确时，先更新显示确认状态，再联系管理员；不要重复提交。

## 趋势自动采集

“趋势自动采集”单独控制微博和知乎，与各关键词的计划互不替代。先确认“启用趋势采集”，再按需要开启自动采集并选择频率和时间，点击“保存趋势计划”。关闭自动采集后，已启用的趋势仍可以手动采集；暂停趋势采集则不再执行手动或自动任务。

## 最近任务与新增结果

“最近任务”区分手动和自动触发，并显示运行时间、状态和本次新增结果数。任务运行中不可重复提交；状态未确认时请联系管理员。

系统不会补跑停机期间遗漏的历史计划。失败不会连续重复执行，后续自动执行按下一次计划时间安排。墨尔本夏令时切换时，重复出现的时间只执行一次；不存在的时间顺延到当天第一个有效时间。

若显示“计划管理尚未启用或暂时不可用”，请联系管理员。不要自行调整其他设置；下方即时搜索和历史结果区仍按既有权限使用。

## 在已加载搜索结果中排序与筛选

搜索结果区域显示本次已加载数量，并在可用时显示已保存结果总数、是否仍有未加载记录。未提供总量时显示总量未知。最多载入最近采集的 **100 条**，不代表全部历史。排序、日期和关键词筛选只处理这些已加载结果，不会重新执行搜索，也不会重新采集内容。

- **综合排序（默认）**：先按最新命中的搜索批次排列，再按该批次的原始搜索名次排列。不同搜索批次不能解释成一个平台总榜；选择关键词后，使用该关键词对应的批次和名次。
- **最新发布**：按已知发布日期从新到旧排列，未知日期放在后面。
- **点赞最多**：按已保存的历史最大观测点赞数排列，未知点赞数放在后面。
- **爆款潜力**：按本地参考分排列，不能当作真实传播效果或平台官方推荐指数。

内容时间范围默认“最近30天”，也可选择最近7天、3个月（90天）、6个月（180天）、1年（365天）及全部；筛选依据发布日期，而不是采集时间。未知或不能确认的发布日期只保留在“全部”中。关键词下拉框只包含当前已加载结果实际命中的关键词。

每条结果展示标题、作者、关键词、发布日期、已保存点赞数、原始搜索名次、爆款潜力分及参考标签、最近采集时间。缺少的信息会明确显示“未知”，不会把缺失点赞数解释为零，也不会用采集时间代替发布日期。已保存点赞数沿用历史非空最大观测值，并非实时点赞；评分也不代表实时热度。来源只提供日期时仅显示日期；有明确时区的完整发布时间转换为墨尔本日期与时间，不补造来源未提供的时刻。

### 爆款潜力参考分

参考分由已采集数据计算，满分 100：点赞占 55%，发布时间的新鲜程度占 25%，最近搜索名次占 15%，历史命中多个关键词占 5%。点赞采用递减增长并在 10,000 赞达到该项上限；新鲜程度每 30 天减半；名次越靠前贡献越高；命中四个及以上关键词达到多关键词项上限。缺少某项时，该项不计分，不把其权重转移给其他项。数据缺失或参考分低不代表内容实际热度低。

“高赞”“最近发布”“搜索排名靠前”“历史命中多个关键词”等标签仅说明已采集数据中的信号。分数的时间基准固定为本次结果读取时间，切换筛选不会重新计算或发起请求；点击“更新显示”重新读取结果后才使用新的时间基准。

最近任务会同时显示开始时间与完成时间（墨尔本时间）。趋势任务正在运行或已暂停时，手动采集按钮不可使用。

## 内容范围、小红书趋势与时间

新增或编辑关键词可保存“默认内容范围”，新关键词默认为30天。选择结果区的已保存关键词时，应用该关键词范围。它仅影响已采集结果的本地展示，不表示只从平台抓取该时间内的内容，与自动计划独立。

趋势按“小红书｜微博｜知乎”查看。小红书趋势基于 Agent Reach 监控关键词及已采集内容生成，仅匹配当前启用关键词，不是官方热榜。可选最近7天、30天、3个月，按爆款潜力、最新、高赞或多关键词命中排列；后者统计当前启用关键词命中数，历史命中关键词另行展示。沿用搜索参考分，不另建评分算法。切换来源、范围、排序、关键词不会触发搜索或采集。微博、知乎继续使用“采集趋势”，不会采集小红书。

来源摘要仅统计最多100条已加载内容；小红书近30天中的高潜力指参考分至少80，不代表全平台热度。未知发布时间不进入有限时间范围。

所有运行、采集、上次与下次执行时间均显示 Australia/Melbourne，格式为日/月/年 时:分，并自动处理夏令时。无法确认时区的原始时刻显示未知，不猜测。自动计划中的08:00始终指墨尔本当地08:00。

### 搜索准备阶段

点击一次“立即运行”后，页面先显示“正在准备搜索环境…”，随后显示“运行中”，按实际结果显示已完成或运行失败。准备与运行期间不可重复提交；自动执行使用同一搜索流程。页面只在当前手动操作期间有界更新已保存的阶段状态，不会再次提交搜索。若显示状态待确认，请等待当前操作返回或使用“更新计划显示”查看记录，不要再次运行来补成功。未保存的趋势计划会保留。
